WLED 控制台 v4 · USB 串口 / WiFi 网络 双通道合一

同一个界面，两种连法：USB 线（Web Serial，不依赖网络）或 WiFi（WebSocket + HTTP）。切换传输方式即可，颜色、状态、日志全部共用。

1. 选择传输方式并连接

未连接
点「连接 USB 串口」后选 USB 串行设备 / USB JTAG/serial debug unit（VID:PID = 303A:1001）。
波特率要和 WLED 里 Sync 设置 → 波特率 一致；60 灯用 115200 足够。改了要「断开」再重连才生效。
⚠ 实测确认：关闭串口会让 ESP32-S3 复位一次（保持打开则不会）。
所以点「断开」、切到 WiFi 模式、或关掉本页面时，灯会短暂灭一下，约 2 秒后自动恢复成 WLED 里保存的状态。
这是 ESP32-S3 内置 USB-Serial-JTAG 的行为，不是面板的 bug。不想让灯闪，就别断开，让它一直连着。
· 连 WLED 自己开的热点 WLED-AP → 地址填 4.3.2.1
· 连同一个家用路由器/局域网 → 填 WLED 的局域网 IP，形如 192.168.1.50
⚠ 别在没连 WLED-AP 的电脑上直接填 4.3.2.1：那是 AMPRNet 的真实公网地址， 若装了 Clash / Mihomo 之类代理，请求会被劫持并返回 HTTP 502。非要用就把 4.* 加进代理绕过列表。
地址栏支持 #ip=192.168.1.50 写法，可存成书签，打开自动填好。

7. 两种传输怎么选 / 用不了怎么办

· USB 串口：不依赖网络，绕开所有 WiFi/代理问题；串口没有广播回声，天然不存在 「发送→回显→覆盖」回路。代价是要插线、只能 Chrome/Edge、COM 口被别的程序占用时连不上， 且断开串口会让板子复位一次（见第 1 节警告）。
· WiFi 网络：可手机控、无需插线；但依赖 IP/路由器，且要注意 4.3.2.1 的代理劫持坑。
· 两者互补：WiFi 挂了用 USB 救场，USB 被占用或不想插线就用 WiFi。
· 必须是 Chrome 或 Edge（USB 模式）：Web Serial 只在 Chromium 内核桌面版可用。双击本地 HTML 即可， file:// 属安全上下文，无需起服务器。
· 若提示不支持串口：在该目录执行 python -m http.server 8000， 再访问 http://localhost:8000/wled控制台.html。
· 这个文件没有任何外部依赖（无 CDN、无字体、无图片），拷到任何一台装了 Chrome/Edge 的电脑都能跑。
